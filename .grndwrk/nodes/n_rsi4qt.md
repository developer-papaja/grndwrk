When I cannot answer a question myself, we need some way to mark it, so it can quickly be taken up with a specific person, or set to something like waiting for an answer, so it is easy to find again later.

For example, in some projects I would want to set them as "Waiting for an answer from Person 1" and "Waiting for an answer from Person 2", and then sit down with Person 1, click "Questions for Person 1" or something like that, and go through all the questions I cannot answer myself.
