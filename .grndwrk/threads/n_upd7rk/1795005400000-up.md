Built two checks.

Rules behind: init now records which grndwrk installed the files. When a file init wrote and nobody changed differs from what the running grndwrk ships (or is new in it), grndwrk says so when it starts, in a line at the top of Status with `grndwrk init` to copy, and at the end of `grndwrk check`, which agents run after writing map files. The map's rules tell the agent to pass it on and run init only if you say so. Files you changed or deleted are left out.

A newer grndwrk: when the map starts, grndwrk asks npm at most once a day, in the background, and prints a line when a later version is out; Status and `check` show the answer it kept. Only the version is asked for. Off with `GRNDWRK_NO_UPDATE_CHECK=1` or `NO_UPDATE_NOTIFIER=1`, in CI, and when grndwrk runs from its source.
