- **Shown** as a strip above the board on the map, folded to one line (how many principles, and the first one) and opened to read them all. Its folded state is kept in the browser. Nothing new in the rail.
- **Steering:** the map's rules tell the agent to read them before building and to say when a change goes against one; `/brief` writes them into the starter CLAUDE.md; `/challenge` asks when a new thought seems to go against one.
- **Changing:** a principle can change as the project matures, and goes back to the map when it no longer holds, but it should feel less changeable than a thought: in the strip it reads as text, with Edit and Move back to the map behind a menu, never edited on a click. A change writes `changed:` with the date, so the agent can see a principle moved.
