The count on the button was every thought about the screen, done ones included, while the board shows what the Status filter lets through, by default everything not done. So five done thoughts gave Work on this part (5) and an empty board. The button now counts what the board will show, comments made on the screen included. And when the board of a part is empty because of the filters, it says how many are out of view, with Show them, which shows every status (ui/src/state.ts, ui/index.html). Not committed yet.

To test:
1. In the Sitemap, open a screen that has some done thoughts and some open ones.
2. With Status: Open in the map's filters, the button says Work on this part with the number of open ones only.
3. Press it: the board shows that many.
4. Set Status to In progress (or anything the screen has none of): the empty board says how many thoughts are out of view, with Show them.
5. Press Show them: every thought about the screen shows, and Status says Everything.
