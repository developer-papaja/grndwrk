How should the filters work together?

Options:
- One Filter menu (the funnel), with sections: Status, New, Who, Waiting for, Type. What is on shows as small chips next to it ("New ×", "Tester ×"), each removed with one click
- A filter bar like Linear: "+ Filter" adds a condition (Status is, Who is, Waiting for, Type is, Topic is, Screen is), and each condition is a chip you can change or remove
- Saved views first: a few ready ones (New comments, Questions waiting for someone, From one person), then one of the above for the rest
