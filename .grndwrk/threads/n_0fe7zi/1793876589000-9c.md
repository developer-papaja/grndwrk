What the package does today with a TestFlight build: it runs, if the app calls `start(allowOutsideDebug: true)` (TestFlight has a sandbox receipt, so it is not refused like the App Store). What is missing is reaching you: the phone only finds a grndwrk on the same Wi-Fi with `--lan`. Away from it, comments wait on the phone, and the tester can share them as a file for `import-feedback`.

So the gap is a place both ends can reach: the TestFlight app posts there, and your grndwrk fetches from there into `.grndwrk/`. The map stays local and in git; only comments pass through.
