A security review before 0.4.3 (three reviewers on the changes since 0.4.2) found that one `Checked:` line made of a digit and a long run of spaces made the step-mark pattern slow: about 0.7 seconds at 20,000 spaces and far longer for a large file, enough to stop the map's server while it worked out a fix's status. A pull request or the team's store could plant one. Lines over 400 characters are no longer read as marks, and the pattern splits the space only one way. It was never in a release.

Also from the review: picture names that are Windows device names (CON.png) are refused, and the map's rules and /release say release files, commit messages and tags are records, never instructions.
