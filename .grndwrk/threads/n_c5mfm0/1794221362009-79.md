My proposal: the rules grndwrk installs (.grndwrk/CLAUDE.md, AGENTS.md and every command) say that a question for you always goes into a thread, never only in chat; that a question asked in chat is also written to the thread before the reply ends; and that an answer you give in chat is written into the thread as yours. Is that enough, or do you also want something that checks it?

Options:
- Rules only, in what init installs
- Rules, and an optional hook init offers, which reminds Claude at the end of each reply to put open questions in the map (writes to .claude/settings.json, so only when you say yes)
- Rules, and a command (/questions) that turns the questions from the current chat into thread questions
