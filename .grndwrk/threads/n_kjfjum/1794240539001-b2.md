grndwrk made a list of its built files once, at start. After an update or a rebuild while it ran, the fresh page asked for a script that list did not know, so the map loaded with its styles but no script. It now reads the files from disk on each request (src/server/index.ts). Committed in a0e5d95.

To test:
1. Restart grndwrk once, so it runs with the fix.
2. Leave it running while grndwrk is rebuilt (npm run build in the grndwrk repo, after a change in the UI), then hard refresh the map: it loads as usual.
