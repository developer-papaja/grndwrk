Only the map tab in view keeps a live connection to grndwrk. When the browser is behind other windows, macOS counts the tab as hidden too, so it had let go of its connection, grndwrk saw no map open, and opened a new tab (in a new window when Chrome was not in front). Now, when a map tab said it was still open in the last two minutes, grndwrk keeps the request and that tab opens the comment, title ready to write, as soon as it comes into view. A tab that is closed says so, so then a new one opens as before (src/server/comments.ts, src/server/events.ts, ui/src/main.ts). Not committed yet.

To test:
1. Restart grndwrk once, so it runs with the fix, and keep one map tab open in Chrome.
2. Put another app's window in front of Chrome, so the map is behind it.
3. On the phone, write a comment and press Write on the Mac.
4. No new tab or window opens. Bring Chrome forward: the map tab opens the comment with its title selected.
5. Close the map tab, then press Write on the Mac again from the phone: a new tab opens, as before.
