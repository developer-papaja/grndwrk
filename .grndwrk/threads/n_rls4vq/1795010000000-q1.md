Who should write down what went into a release?

Options:
- Your agent, when it ships or tags a release: the map's rules tell it to write the release file with what was built since the last one
- A command you run when you release (/release 0.4.3), which writes the file and shows it to you first
- Read from git tags by itself: a story counts as released in the first tag whose commits cite its id (only for projects that tag releases)
