Done for grndwrk itself: Biome 2.6.4 (pinned, released 28 October, so not brand new), `npm run lint`, and a lint step in GitHub Actions on macOS and Windows. The recommended rules, minus five the code breaks on purpose: non-null assertions, comma and assignment expressions in the button's script, control characters in the regexes that clean text from devices, and `innerText` where only visible text should count as a label. The 40 or so real findings are fixed (needless regex escapes, optional chains, two unused names, untyped variables, callbacks that returned a value by accident).

Not on: its formatter. It would have rewritten 63 files (1,765 lines added), mostly by breaking short one-line chains over several lines, against the code's dense style, and every open branch would conflict with it. Formatting stays by hand for now. Say if you want it on anyway, as one commit of its own.
