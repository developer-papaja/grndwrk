Built on the branch `shared-store` (not merged into main, not pushed, nothing deployed).

- The store protocol (`docs/store-protocol.md`): a few HTTP calls over the map's files, roles read, write and comment, and `grndwrk store check` to test any store. Adapters (one `.mjs` file) run only once allowed on each machine, and stop when they change.
- Three example stores to copy and change: Cloudflare, Firebase (functions and an adapter), PHP. Each passes the check; the PHP one against a real PHP server, the others against stand-ins.
- The sync: `.grndwrk/` stays the agent's working copy, kept in step with the store; nothing is lost on a conflict, a store switch deletes nothing, many deletes at once stop and ask. `grndwrk store use / sync / leave / login / allow / assets`, and init asks where a new map is kept.
- Comments straight to the store from a staging site or the phone, with Test, Approve and Reject; limits per commenter.
- The page: the map served by the store, with a sign-in, the Inbox, the map, adding thoughts; All projects across a store; views saved for everyone (on the Mac too).
- A security review of all of it, and its findings fixed.

To test:
1. On your Mac, copy `stores/php/` somewhere, follow its README (SQLite), make a write token with `php admin.php token add clinic write`, and run `php -S 127.0.0.1:8080 -t public`.
2. Run `grndwrk store check http://127.0.0.1:8080/clinic/ --token <the token>`: every rule says ok.
3. In a scratch project with a map, run `grndwrk store use http://127.0.0.1:8080/clinic/` and give the token, then `grndwrk`: it says it synced, and the store holds the map.
4. Run `grndwrk store assets <the PHP store's page folder>` (its README says which), open `http://127.0.0.1:8080/clinic/`, sign in with the token, and answer a question in the Inbox: the answer appears in the scratch project's map within a few seconds.
5. Make a comment token (`php admin.php token add clinic comment --commenter phone_test01 --name "Front desk"`), add the store's `store.js` line to a local test page per the README, join with the store link, and send a comment: it becomes a card on the Feedback page from "Front desk".
