Taken from the answers: across apps the team needs the overview, the thoughts themselves searchable and linked across apps, and shared personas, segments and design principles defined once. A workspace of repos is not enough: some systems have no repo for a map, and some people never clone one. So the map should also be reachable as a page under the team's own domain, with a login, so someone can help without having the project. The commands stay in each repo. Hosted by the team, on Cloudflare as with the relay or on its own server or database (Postgres or similar); a hosted grndwrk service last.

This changes the proposal: the shared store is the source of truth, with a web page on top that people log in to, and each repo keeps a working copy of its map in `.grndwrk/` for its agent, synced with the store.
