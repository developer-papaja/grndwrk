Taken from the answer: an adapter too. To keep a pull request from running code on someone's Mac, grndwrk loads a team's adapter only after the person allowed that exact file, like direnv: `grndwrk store allow` keeps a hash of it in the per-user folder, never in the project. When the file changes (a pull, a branch), grndwrk stops and says so, shows what changed, and waits for `grndwrk store allow` again. The adapter speaks the same calls as the protocol, so `grndwrk store check` tests it the same way.
